# Starry Dreamland｜3D 樂園持續開發路線

## 美術方向
- 風格：精緻、神秘、夢幻的夜間星際遊樂園。
- 主色：深藍、紫羅蘭、銀白、暖金與柔和粉紫。
- 建築以城堡、星象裝置、晶石花園、玻璃燈籠、雕花步道與精緻遊樂設施建立統一語言。
- 目前使用 Three.js 程序化模型與材質；後續逐項替換為授權清楚、高完成度的 GLB/glTF 模型，不以堆疊零碎裝飾代替完整模型設計。
- 每個外部資產記錄作者、來源、授權、下載日期與用途。

## 已完成的核心系統
- 第一人稱自由探索與第三人稱切換。
- 桌面 WASD／方向鍵、Shift、滑鼠拖曳與 E 互動。
- 手機橫向提示、全螢幕、虛擬搖桿、奔跑與互動按鈕。
- 左上角 2D 園區地圖、在線玩家位置、12 個地標探索手帳。
- 五種可搭乘設施：旋轉木馬、星月茶杯、摩天輪、自由落體與雲霄飛車。
- 五種旅人類型、六套服裝、髮型／髮色／膚色／星紋與眼睛光色設定，具備 3D 即時預覽並保存至 Supabase。
- 即時在線玩家、公共聊天泡泡與快速表情。
- 沒有預設假路人；NPC 仍暫緩，待每個 NPC 都有明確外觀、身分與行為設計後再加入。

## Phase 1：高完成度資產與美術一致性（目前優先）

### 2026-11-18 開發批次：既有髮型的立體層次
- 在不新增外觀欄位、不改動 Supabase JSONB／RPC／RLS 的前提下，為長髮、雙馬尾、短髮與兜帽四種既有髮型補上低細分曲線髮束、瀏海／側髮輪廓及髮絲高光。
- 髮束採少量 TubeGeometry，避免引入外部模型、貼圖或額外下載；保留既有髮型識別值與舊玩家外觀相容性。
- 新增 Node 結構測試，以輕量 Three.js mock 建立四種髮型並檢查髮束數量；此測試只驗證模型建構路徑，不等同真實 WebGL 畫面或手機效能驗收。

### 2026-11-19 開發批次：旅人五官輪廓精修

### 2026-11-20 開發批次：旅人快速造型預設
- 在角色工坊新增四組快速預設：「月霧銀影」、「暮紫星紗」、「晨曦金羽」與「深海幻光」，一次套用既有髮型、髮色、膚色及星紋／眼睛光色組合。
- 預設只更新編輯器控制項與即時 3D 預覽；使用者仍須明確按下「保存角色設定」才會保存，不會自動呼叫雲端 RPC、扣除星塵或更改已裝備服裝。
- 預設只使用既有 appearance keys 與白名單值，不新增 JSONB 欄位、不修改 Supabase schema／RLS／RPC／migration，舊玩家資料可直接沿用。
- 新增 `tests/avatar-presets.test.mjs`，驗證四組預設只使用既有欄位及允許值、套用動作不執行保存／扣款，以及手機版按鈕排版與無障礙狀態。
- 自動化測試仍不等同真實瀏覽器 WebGL／觸控實機驗收。


### 2026-11-21 開發批次：外觀草稿隨機與還原

- 還原操作會讀取目前已載入的玩家資料，恢復已保存的旅人類型、髮型、髮色、膚色、星紋／眼睛光色及已裝備服裝預覽。
- 狀態提示區分「已保存」與「尚未保存」；隨機、預設及還原均只更新本機編輯器與 3D 預覽，只有明確按下保存按鈕才會呼叫既有安全 RPC。

- 新增測試驗證隨機值白名單、還原資料一致性、預覽更新及不寫入／不扣款。測試不等同真實瀏覽器 WebGL 與手機觸控驗收。

## NPC 原則（暫緩）
- 先定義角色身分、個性、視覺概念、活動時段、路線、對話與互動。
- 未完成上述設計前，不在園區生成任何 NPC。
- NPC 不得冒充在線玩家，也不能出現在玩家在線名單。

## 技術與驗收
- 網頁入口維持原生 `index.html`；3D 使用固定版本 Three.js。
- 模型載入失敗或 WebGL 不可用時，保留遊戲卡片與基本導覽。
- 桌面與手機都要可操作；手機橫向提供觸控搖桿。
- 角色不能穿過建築、地形或設施；下車必須找到安全可行走位置。
- 每次大型變更先跑語法、模型建立、互動流程測試，再做真實瀏覽器／WebGL 驗收。
- 不得把靜態檢查或模擬測試當作實機視覺驗收。
