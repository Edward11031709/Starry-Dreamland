# Starry Dreamland 未來遊戲提案

以下是未來可加入的遊戲候選，並非目前版本已完成的功能。

1. **水晶折射 Crystal Refraction**：旋轉水晶調整光束方向，照亮指定星體。類型：空間解謎。
2. **星軌航行 Orbital Voyage**：控制小型星際飛船穿越軌道、避開障礙並抵達目的地。類型：操作／反應。
3. **星雲攝影 Nebula Capture**：在限定時間捕捉移動星雲，考驗觀察與構圖。類型：觀察／時機。
4. **月蝕解碼 Eclipse Cipher**：觀察月相與星象符號，依線索破解宇宙密碼。類型：邏輯解謎。
5. **星際運動挑戰 Cosmic Sports**：待星際競技館開放後加入籃球、足球或競速等運動遊戲。

建議一次新增一款，先完成可玩流程、計分及回到廣場，再加入 3D 動畫。
