# Starry Dreamland｜星夢樂園

**以瀏覽器直接開啟的星空奇幻遊戲平台。**

正式網址：https://edward11031709.github.io/Starry-Dreamland/

## 目前版本：Three.js 3D 中央廣場第一階段

首頁已加入即時 3D 主廣場，採固定斜上方鏡頭，包含主浮空島、城堡、觀測塔、遠方星球、星塵晶體、雲海及三座可點擊挑戰星門。

- 3D 引擎：Three.js r187，固定版本 CDN 載入，不需要安裝工具。
- 3D 場景：目前使用程式生成的幾何體建立第一階段空間原型，**尚未換成最終授權 GLB/glTF 美術模型**。
- WebGL 或 CDN 載入失敗時，仍可使用下方 HTML 遊戲卡片進入挑戰。
- 可使用「訪客預覽」先查看 3D 廣場；訪客成績不會寫入雲端或保存。
- 自由移動、滑鼠旋轉鏡頭仍留到最後階段。

## 遊戲分區

### 星夢遊戲
- **月相共鳴**：12–15 拍不規則節奏挑戰，每局速度不同。
- **星域解碼**：從符號與位置線索推理四位密碼。
- **軌道接線**：在 5 × 5 隨機管線矩陣中旋轉節點，連接能源起點與星門出口。

### 星芽探索區
- **星星連連看**：隨機星點位置的順序連線遊戲。
- **星星記憶**：每局重新洗牌的圖案配對。
- **星座校準**：較輕鬆的星點連線挑戰。
- **引力迷航**：隨機生成迷宮、尋找兩枚星塵碎片並抵達出口。

星芽遊戲會獨立累積星塵並設有自己的排行；其他遊戲沿用星夢排行榜。星際競技館目前尚未開放。

## 全球帳號與雲端資料

星夢樂園已建立 Supabase 專案，並建立：
- sd_profiles：玩家暱稱及帳號資料。
- sd_game_records：一般遊戲／星芽遊戲分區、分數、狀態及星塵獎勵。
- 個人遊玩紀錄及全球最佳成績 RPC。
- RLS 存取政策；內部高權限函式放在未公開的 private schema。

網站已接上 Supabase JavaScript SDK、電子郵件註冊／登入／登出／重設密碼、個人資料同步、成績同步及全球排行榜。

首次正式註冊前，專案擁有者仍須在 Supabase Dashboard → Authentication → URL Configuration 設定：

- Site URL：https://edward11031709.github.io/Starry-Dreamland/
- Redirect URLs：加入同一個完整網址。

網站只使用公開 Publishable key；不可將 sb_secret_、service_role、資料庫密碼或管理員金鑰放進公開 Repository。

舊版本機展示資料不會自動匯入雲端帳號。遊戲分數現由瀏覽器計算，正式競技前仍需伺服器端驗證。

## 關卡變化

每次開始遊戲都會重新生成節奏、密碼、管線、星點位置或迷宮路線，不再使用固定順序與同一張迷宮地圖。

## GitHub Pages 發布

Repository 已有 GitHub Actions 發布流程，更新 main 分支後會自動部署。Three.js 透過固定版本 CDN 載入；若 CDN 暫時無法連線，遊戲卡片仍保留可用。
