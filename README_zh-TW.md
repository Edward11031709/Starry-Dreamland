# Starry Dreamland｜星夢樂園

**以瀏覽器直接開啟的星空奇幻 3D 遊樂園。**

正式網址：https://edward11031709.github.io/Starry-Dreamland/

## 目前版本

首頁是可自由探索的 3D 夜遊園，預設以第一人稱視角進入，也能切換第三人稱查看角色。場景包含中央星象廣場、星夢城堡、星辰觀測站、晶石花園、遠方星球、雲海與主題設施。

- Three.js r187，固定版本 CDN 載入，不需要安裝工具。
- 桌面以 WASD／方向鍵移動、Shift 奔跑、滑鼠拖曳環顧、E 互動。
- 手機建議橫向遊玩，使用虛擬搖桿移動、奔跑按鈕與互動按鈕。
- 左上角 2D 園區地圖會顯示主要地標與目前位置。
- WebGL 或 CDN 載入失敗時，仍可使用下方遊戲卡片進入遊戲。
- 場景目前仍以程序化 Three.js 幾何體為主；正逐步提高模型、材質與動畫細節，尚未全部換成最終授權 GLB/glTF 資產。

## 遊樂設施

目前五種設施都可以靠近後按 E 或使用手機互動鍵搭乘，乘坐時會跟隨設施移動，也可以安全下車：

- **星光旋轉木馬**
- **星月茶杯**
- **星河摩天輪**
- **星際自由落體**
- **星際雲霄飛車**

星夢入園票亭是園區服務點，不是小遊戲入口。

## 遊戲區

### 星夢遊戲
- **月相共鳴**：12–15 拍不規則節奏挑戰，每局速度不同。
- **星域解碼**：從符號與位置線索推理四位密碼。
- **軌道接線**：在 5 × 5 隨機管線矩陣中旋轉節點，連接能源起點與星門出口。
- **霓虹神射手**：限時反應靶場。
- **幻影鏡屋**：漸進式光影記憶挑戰。

### 星芽探索區
以下是以輕鬆玩法為主的遊戲，卡片會以「星芽遊戲」標示：
- **星星連連看**：隨機星點位置的順序連線遊戲。
- **星星記憶**：每局重新洗牌的圖案配對。
- **星座校準**：較輕鬆的星點連線挑戰。
- **引力迷航**：隨機生成迷宮、尋找兩枚星塵碎片並抵達出口。

星芽遊戲會獨立累積星塵並設有自己的排行；其他遊戲沿用星夢排行榜。

## 旅人角色工坊

首頁可進入「旅人角色工坊」，選擇五種旅人類型、六套服裝，並調整髮型、髮色、膚色與星紋／眼睛光色。角色可在真正的 3D 預覽中旋轉查看；服裝可以先預覽再決定是否解鎖。登入後的外觀設定會保存到 Supabase，並同步給其他在線旅人。

## 探索與多人互動

- **星境探索手帳**：親自步行走訪 12 個園區地標，解鎖探索紀錄與 4／8／12 處里程碑。
- **即時旅人**：只顯示真正登入且在線的玩家，不生成假路人；NPC 仍留待之後規劃。
- **旅人會客廳**：在線玩家可即時聊天，訊息會短暫顯示在角色上方。
- **快速表情**：揮手、星光、月亮與愛心。

## 帳號與雲端資料

星夢樂園使用 Supabase 保存：
- sd_profiles：玩家暱稱、角色服裝與外觀設定。
- sd_game_records：一般遊戲／星芽遊戲分區、分數、狀態及星塵獎勵。
- 個人遊玩紀錄、全球最佳成績與探索手帳紀錄。
- RLS 存取政策；內部高權限函式放在未公開的 private schema。

網站已接上電子郵件註冊／登入／登出／重設密碼、個人資料同步、成績同步、探索紀錄與全球排行榜。

首次正式註冊前，專案擁有者仍須在 Supabase Dashboard → Authentication → URL Configuration 設定：

- Site URL：https://edward11031709.github.io/Starry-Dreamland/
- Redirect URLs：加入同一個完整網址。

網站只使用公開 Publishable key；不可將 sb_secret_、service_role、資料庫密碼或管理員金鑰放進公開 Repository。

遊戲分數現由瀏覽器計算，正式競技前仍需伺服器端驗證。

## 管理員版本審核中心

管理員帳號通過資料庫端 `sd_is_admin()` 驗證後，導覽列才會顯示「管理中心」。中心會讀取目前 `main`、開啟中的 PR、版本標籤及歷史提交，提供差異與自動檢查連結。此中心不會直接部署或修改玩家資料；正式發布仍須依 `docs/RELEASE_WORKFLOW_zh-TW.md` 的人工核准流程。私有預覽由 Supabase Edge Function 直接從公開 GitHub commit 匯入靜態檔案至 Private Storage，再簽發短效預覽連結；整個流程只允許資料庫驗證過的管理員操作，不需要 GitHub Actions secrets，也不會把候選版本放到公開 GitHub Pages。正式發布仍須另外經由 owner 手動核准。設定與使用方式見 `docs/ADMIN_PREVIEW_SETUP_zh-TW.md`。
